# ChalkAI

A mobile-first React + TypeScript + Vite starter for ChalkAI.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Verify the production build with `npm run build` and optionally run `npm run preview`.

## Deploy to Vercel

Import this repository into Vercel. Vercel detects Vite automatically; use `npm run build` as the build command and `dist` as the output directory. `vercel.json` includes a fallback rewrite for client-side routes.

## Current scope

This is the simple home page and project foundation only. Start Learning gives an honest coming-soon message. It does not collect accounts or call an AI service. No API keys are needed in the frontend.
